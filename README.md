# ルノアール暗記用

お店のレシピを、注文どおりに作りながら覚えるWebゲームです。
ビルド作業は不要で、フォルダをそのまま Netlify に置けば動きます。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面の骨組み |
| `style.css` | 見た目 |
| `app.js` | ゲームの処理 |
| `data.js` | メニュー・材料・器・切り方のデータ(ここを変えるとレシピが変わります) |
| `netlify.toml` | Netlify の設定(公開フォルダとキャッシュ) |

## Netlify への公開

**いちばん簡単な方法(Netlify Drop)**

1. https://app.netlify.com/drop を開いてログインします。
2. このフォルダ(`index.html` が入っているフォルダ)を画面にドラッグ&ドロップします。
3. 表示された URL を開けば遊べます。

更新するときは、Netlify の管理画面でサイトを開き、「Deploys」にフォルダをもう一度ドラッグ&ドロップします。

**GitHub と連携する方法**

フォルダを GitHub のリポジトリに入れ、Netlify で「Import an existing project」からそのリポジトリを選びます。
ビルドコマンドは空欄、公開ディレクトリは `.` のままで大丈夫です(`netlify.toml` に書いてあります)。
以後は `data.js` を更新して push するだけで自動的に公開されます。

> 公開した URL は、知っている人なら誰でも開けます。お店のレシピを載せてよいか、事前にお店のルールを確認してください。

## 遊び方

| モード | 内容 |
| --- | --- |
| 練習 | 1品ずつ注文が出ます。10品続けて作ります |
| 実践編 | テーブルの伝票に2〜4品が並びます。器・お皿選びから自分で判断して全部作り、伝票ごと提供します |
| レシピ帳 | 全メニューの分量・切り方・手順の一覧です |

フードで切り方が登録されているメニューは、カウンターの「カット」に切り替えて、パンの上を指でなぞって線を入れます。
「切込み」(点線)と「カット」(実線)を切り替えて使います。

## レシピの直し方

`data.js` を書き換えて、Netlify にもう一度アップロードしてください。全員のゲームに反映されます。

`data.js` は `window.GAME_DATA = { ... };` という形の JSON です。
直したら、先頭の `version` も別の文字に変えてください(更新した日付など。どの版かを見分ける目印です)。

```js
window.GAME_DATA = {
  "version": "2026-10-18-1",
  "vessels": [ ... ],
  "ingredients": { ... },
  "recipes": [ ... ]
};
```

#### vessels(器)

```json
{ "name": "タンブラー", "shape": "tumbler" }
```

| 項目 | 説明 |
| --- | --- |
| `name` | 器の名前。レシピの `vessel` と同じ文字にします |
| `shape` | 絵の形。`rock`(ロックグラス)/ `tumbler` / `glass`(背の高いグラス)/ `mug` / `jug` |

#### ingredients(材料)

キーが材料のID(英数字)で、レシピからはこのIDで参照します。

```json
"milk": {
  "name": "牛乳",
  "cat": "drink",
  "group": "ミルク・お茶・お湯",
  "kind": "liq",
  "vis": "liquid",
  "icon": "carton",
  "color": "#fbf7ee",
  "unit": "",
  "step": 5
}
```

| 項目 | 説明 |
| --- | --- |
| `name` | 棚に表示する名前 |
| `cat` | `drink`(ドリンクの棚)か `food`(フードの棚) |
| `group` | 棚の中の見出し。同じ見出しの材料がまとまって並びます |
| `kind` | 入り方。ドリンク:`liq`(液体)/ `pow`(粉)/ `top`(トッピング)。フード:`layer`(のせる・はさむ)/ `side`(添える) |
| `vis` | 器や皿の中での見た目。`liq`→`liquid`、`pow`→`powder`、`top`→`whip` `scoop` `fruit` `slice` `ice` `pudding` `blob`、`layer`→`band` `bread` `dots` `wave`、`side`→`soup` `egg` `bowl` `cup` `scoop` `dish` |
| `icon` | 棚のアイコン。`pot` `bottle` `carton` `jar` `shaker` `tub` `round` `sheet` `cube` `ball` `can` `pudding` `bread` `leaf` `egg` `pack` |
| `color` | 色(`#rrggbb`) |
| `unit` | 単位(`g` `ml` `枚` など。空でもよい) |
| `step` | 1タップで増える量 |
| `thickness` | (`layer` のみ)重ねたときの見た目の厚み |
| `once` | `true` にすると、量を指定しない材料になります(タップ1回で入り、入っていれば正解)。ドリンクのトッピングと粉は常に `true` です |
| `neutral` | `true` にすると、レシピにないときは入れても間違いになりません(氷など) |

#### recipes(レシピ)

```json
{
  "id": "cafeaulait",
  "name": "カフェオーレ",
  "cat": "drink",
  "look": "hot",
  "items": { "milk": 80, "drip": 80 },
  "note": "結果画面とヒントに出る説明",
  "stepsTitle": "作り方の順番",
  "steps": ["手順1", "手順2"]
}
```

| 項目 | 説明 |
| --- | --- |
| `id` | メニューのID。ゲームの記録はこのIDで残るので、途中で変えないでください |
| `name` | メニュー名 |
| `cat` | `drink` か `food` |
| `look` | ドリンクの種類。`hot` / `ice` / `dish`(デザート)。フードは `food` |
| `container` | (任意)正解の器・お皿。`mug`(ホットカップ)/ `ame`(アメカップ)/ `tea`(ティーカップ)/ `glass`(ジュースグラス)/ `parfait`(パフェグラス)/ `dish`(ケーキ皿)/ `plate`(コレール皿)/ `big`(大皿)/ `tray`(プレート皿)。省略すると、HOTはホットカップ、ICEはジュースグラス、デザートはケーキ皿、フードはコレール皿になります |
| `vessel` | (任意)`vessels` に登録した器の名前。`container` の代わりに使います |
| `bake` | (任意)トースター。`none`(焼かない)/ `toast`(焼く)/ `open`(開き焼)。省略すると判定しません |
| `micro` | (任意)レンジの秒数。`0`(使わない)/ `40` / `90` / `180` など。レシピに書いた秒数が、ゲームのレンジの選択肢になります。省略すると判定しません |
| `items` | 材料IDと分量。数字=その量ちょうど、`[5, 6]`=5〜6の範囲、`null`=入っていれば正解 |
| `note` | (任意)メモ |
| `stepsTitle`, `steps` | (任意)手順。レシピ帳に表示されます |
| `cut` | (任意・フードのみ)切り方。下の説明を参照 |

#### cut(切り方)

```json
"cut": {
  "scoreFirst": true,
  "lines": [
    { "t": "score", "a": [0.25, 0], "b": [0.25, 1] },
    { "t": "cut",   "a": [0, 0.4],  "b": [1, 0.62] }
  ]
}
```

| 項目 | 説明 |
| --- | --- |
| `lines` | 線の一覧。`t` は `score`(切込み・点線)か `cut`(カット・実線)。`a` と `b` は線の両端で、パンの左上を `[0,0]`、右下を `[1,1]` とした位置です |
| `scoreFirst` | `true` にすると「切込みをすべて入れてからカットする」順番も判定します |
| `anyTurn` | `true` にすると、パンを90度回した切り方も正解にします(「真ん中で二等分」など向きが決まっていないもの) |

線の位置は、なぞった線と端の点が 0.12(パンの一辺の12%)以内なら正解になります。この値は `app.js` の `CUT_TOL` で変えられます。

パンを回したり裏返したりして同じ切り上がりになる入れ方は、すべて正解になります(縦3等分と横3等分、右下がりと左下がりの対角線など)。登録する線は、どれか1つの向きで引けば大丈夫です。

## 記録について

ゲームの記録(覚えたメニューなど)は、各ブラウザの localStorage に保存されます。
ブラウザのデータを消すと記録も消えます。端末どうしで記録は共有されません。
